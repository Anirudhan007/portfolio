# Anirudhan Krishnan Portfolio

A single-page portfolio for [anirudhan.xyz](https://anirudhan.xyz), built with semantic HTML, CSS, vanilla JavaScript, Three.js, and GLSL.

## Design system

Dark scientific interface with a scroll-driven particle organism that morphs through five states. Space Grotesk carries display copy and JetBrains Mono handles labels and readouts.

## Pages

* Introduction
* Selected work
* Experience
* Education and toolkit
* Contact

## Local preview

Run a static server from the project root:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.
